Sobre este blog

Este es mi cuaderno de estudio mientras aprendo Java y su ecosistema para backend: el lenguaje en sí, JVM, Spring / Spring Boot, persistencia (JDBC, JPA/Hibernate), APIs REST, testing, mensajería, contenedores y despliegue.

La idea es ir documentando lo que voy entendiendo, con ejemplos de código y enlaces a fuentes, tanto para consolidar el conocimiento como para tener algo consultable a futuro.

El código fuente de este blog está pensado para ser simple: HTML, CSS y JS vanilla, sin frameworks ni build tools. Los posts se escriben en Markdown.
